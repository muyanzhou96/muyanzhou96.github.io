This site is a Jekyll-based personal homepage for Yanzhou Mu.

Key content files:

* `_config.yml`: site title, SEO metadata, author profile, and contact fields.
* `_pages/about.md`: homepage content.
* `_pages/cv.md`: Markdown CV page.
* `_publications/`: publication entries extracted from the LaTeX resume.
* `_portfolio/`: project entries extracted from the LaTeX resume.
* `images/profile.jpg`: public profile photo copied from `resume/person2.jpg`.
* `resume/`: local resume source files, excluded from the generated public site.
