# Markdown Generator

This directory contains helper scripts for creating Markdown entries for this site. In general, filenames that end with `.ipynb` or `.py` are similar, but may contain different documentation or are intended to be run from GitHub when deploying the site.

## Python Scripts

The `.py` files can be run from the command line, for example `python3 publications.py publications.csv`.

## Jupyter Notebooks

The `.ipynb` files are local generation helpers. They are excluded from the generated public site.
