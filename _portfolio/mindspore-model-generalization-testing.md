Developed a Model structure generalization tool based on the domestic deep learning framework MindSpore. The tool extracts feature factors, ranges, and constraints of mainstream CV and NLP model architectures, modifies model structures, and performs testing to detect defects.

The project results were an essential part in supporting the collaboration team to win the Huawei 2023 Innovation Testing Application Award.
